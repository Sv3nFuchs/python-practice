# Python Practice:

Simple Python programs from previous computer science courses (AP Computer Science Principles).

## Projects:

- **state-capitals**: Console-based quiz that asks for the capital of a random US state and tracks the user's score. User types `exit` to quit.
- **unit-circle-quiz**: Console-based quiz on unit circle coordinates. Given a random angle in radians, the user enters the matching coordinates as (x, y) using either `sqrt` or `√`. The user types 'Exit' to quit, showing a final score and percentage. Built with a classmate.

## Running a program:

Requires Python 3.

```
python3 state-capitals/main.py
python3 unit-circle-quiz/main.py
```
